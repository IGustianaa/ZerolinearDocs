Koleksi Template Prompt Siap Pakai

Berikut 8+ template prompt yang dapat langsung digunakan dan diadaptasi. Setiap template dilengkapi dengan full prompt text dan expected output format.

1. Code Review

Prompt:

Anda adalah senior software engineer dengan spesialisasi 
code review. Review kode berikut dengan fokus pada:

1. BUGS: Logika yang salah, edge case tidak tertangani, 
 race condition, memory leak
2. SECURITY: Injection, XSS, CSRF, data exposure
3. PERFORMANCE: N+1 query, unnecessary allocation, 
 blocking I/O
4. READABILITY: Naming, complexity, duplication
5. BEST PRACTICES: Pattern adherence, SOLID principles

Untuk setiap issue, berikan:
- Severity: CRITICAL / HIGH / MEDIUM / LOW
- Category: BUG / SECURITY / PERFORMANCE / STYLE
- Description: Jelaskan masalah
- Suggestion: Code fix dengan penjelasan

Kode untuk review:

{code}


Format output sebagai JSON array.

Expected Output:

[
 {
 "severity": "HIGH",
 "category": "SECURITY",
 "line": 42,
 "description": "SQL query menggunakan string concatenation, rentan SQL injection",
 "suggestion": "Gunakan parameterized query: db.query('SELECT * FROM users WHERE id = ?', [userId])"
 },
 {
 "severity": "MEDIUM",
 "category": "PERFORMANCE",
 "line": 15,
 "description": "Loop dalam loop menyebabkan O(n^2) complexity",
 "suggestion": "Gunakan Map untuk lookup O(1): const userMap = new Map(users.map(u => [u.id, u]))"
 }
]

2. Data Extraction

Prompt:

Ekstrak informasi struktural dari teks berikut. 
Isi field yang tidak disebutkan dengan null.

Schema:
{
 "person": {
 "name": "string|null",
 "title": "string|null",
 "organization": "string|null"
 },
 "contact": {
 "email": "string|null",
 "phone": "string|null",
 "address": "string|null"
 },
 "event": {
 "date": "YYYY-MM-DD|null",
 "type": "meeting|deadline|other|null",
 "description": "string"
 }
}

Teks:
---
{raw_text}
---

Hanya kembalikan JSON, tanpa teks tambahan.

Expected Output:

{
 "person": {
 "name": "Dr. Sarah Wijaya",
 "title": "Head of Research",
 "organization": "Tech Innovate Inc."
 },
 "contact": {
 "email": "s.wijaya@techinnovate.com",

 "address": null

 "event": {
 "date": "2025-02-15",
 "type": "meeting",
 "description": "Quarterly review meeting with product team"
 }
}

3. Summarization

Prompt:

Rangkas dokumen berikut dalam format yang terstruktur.

<DOKUMEN>
{document_text}
</DOKUMEN>

Output format:

## Executive Summary
[3 kalimat yang merangkum poin utama]

## Key Points
- [Poin 1: maksimal 1 kalimat]
- [Poin 2]
- [Poin 3]
- [Max 7 poin total]

## Action Items
- [Siapa] harus [melakukan apa] pada [kapan]
- [Jika tidak ada action item, tulis "Tidak ada"]

## Open Questions
- [Pertanyaan yang belum terjawab dalam dokumen]
- [Jika tidak ada, tulis "Tidak ada"]

## Key Metrics / Numbers
- [Setiap angka, persentase, atau metrik penting]

Batasan:
- Pertahankan akurasi faktual, jangan menambahkan informasi
- Jika informasi tidak ada dalam dokumen, jangan mengarang
- Max 400 kata total

4. Translation

Prompt:

Anda adalah penerjemah profesional bersertifikasi.

Terjemahkan teks berikut dari {source_lang} ke {target_lang}.

Aturan:
1. Pertahankan nuansa dan tone asli
2. Untuk istilah teknis, berikan terjemahan lalu 
 istilah asli dalam kurung pada first mention
3. Untuk idiom, gunakan ekspresi yang setara di 
 bahasa target, bukan terjemahan literal
4. Pertahankan format: paragraf, bullet points, 
 heading, numbering
5. Jika ada kata yang ambigu, berikan catatan 
 dengan format: [CATATAN: ...]

<TEKS_ASLI>
{source_text}
</TEKS_ASLI>

Output hanya terjemahan, dimulai langsung tanpa pembuka.

Expected Output:

Laporan Kinerja Triwulanan Q4 2024

Pendapatan total mencapai Rp 45.2 miliar, meningkat 
23% year-over-year (YoY). Segmen enterprise (B2B) 
menyumbang 68% dari total pendapatan.

[CATATAN: "enterprise" dipertahankan karena istilah 
standar industri di Indonesia]

Poin kinerja utama:
- Akuisisi 1,240 pelanggan baru
- Churn rate turun ke 4.2% (dari 6.1% di Q3)
- Net Revenue Retention (NRR) mencapai 115%

5. Code Generation

Prompt:

Anda adalah senior engineer. Tulis fungsi {language} 
yang memenuhi spesifikasi berikut:

FUNGSI: {function_name}
DESKRIPSI: {description}

INPUT:
- {param1}: {type} - {description}
- {param2}: {type} - {description}

OUTPUT:
- Return type: {return_type}
- {description_of_return}

EDGE CASES yang HARUS ditangani:
1. Input null/empty -> return {expected}
2. {edge_case_2}
3. {edge_case_3}

REQUIREMENTS:
- Type hints wajib
- Docstring dalam format Google style
- Logging untuk error cases (level: WARNING)
- Tidak boleh ada dependency eksternal selain stdlib
- Cyclomatic complexity < 10

Sertakan 3 unit test cases (1 normal, 1 edge case, 
1 error case) menggunakan {test_framework}.

Expected Output:

from typing import List, Optional
import logging

logger = logging.getLogger(__name__)

def parse_csv_line(
 line: str, 
 delimiter: str = ",",
 quote_char: str = '"'
) -> List[str]:
 '''Parse a single CSV line into fields.
 
 Args:
 line: Raw CSV line string.
 delimiter: Field delimiter character.
 quote_char: Quote character for escaping.
 
 Returns:
 List of parsed field values.
 
 Raises:
 ValueError: If line is empty or malformed.
 '''
 if not line or not line.strip():
 logger.warning("Empty CSV line received")
 return []
 
 # ... implementation ...
 return fields

# Tests
import pytest

class TestParseCsvLine:
 def test_normal(self):
 assert parse_csv_line('a,b,c') == ['a', 'b', 'c']
 
 def test_quoted_field(self):
 assert parse_csv_line('"hello, world",b') == ['hello, world', 'b']
 
 def test_empty_line(self):
 assert parse_csv_line('') == []

6. Debugging

Prompt:

Anda adalah debugging expert. Analisis error berikut 
dan bantu menyelesaikannya.

BAHASA: {language}
FRAMEWORK: {framework}

ERROR MESSAGE:
{error_message}
{stack_trace}
{code_snippet}

CONTEXT:
- Apa yang sedang dilakukan: {user_action}
- Terakhir yang berfungsi: {last_working_state}
- Perubahan terbaru: {recent_changes}

Analisis dengan struktur:
1. ROOT CAUSE: Penjelasan teknis mengapa error terjadi
2. WHY: Mengapa kondisi ini terjadi (bukan hanya gejala)
3. FIX: Code solution lengkap dengan penjelasan
4. PREVENTION: Cara mencegah di masa depan
5. RELATED: Issue terkait yang mungkin perlu dicek

Jika informasi tidak cukup untuk diagnosis, tanyakan 
pertanyaan klarifikasi sebelum memberikan solusi.

7. Documentation Generation

Prompt:

Anda adalah technical writer. Untuk dokumentasi API 
dari kode berikut.

KODE:

{code}


Untuk dokumentasi dalam format:

## {Function/Class/Endpoint Name}

### Description
[1-2 kalimat menjelaskan purpose]

### Parameters

Item
Name | Type | Required | Description |
------|------|----------|-------------|
... | ... | ... | ... |
### Returns
[Type dan description]

### Raises

Item
Exception | Condition |
-----------|-----------|
... | ... |
### Example

// Usage example


### Notes
- [Important caveats, performance notes]

Aturan:
- Untuk fungsi private (_prefix), tetap dokumentasikan 
 tapi tandai sebagai internal
- Sertakan example yang realistis, bukan placeholder
- Jika ada side effects (DB write, file I/O, network), 
 sebutkan eksplisit

8. Email Drafting

Prompt:

Tulis email profesional berdasarkan parameter berikut.

KEPADA: {recipient_role}
DARI: {sender_role}
KONTEKS: {situation_description}
TUJUAN: {desired_outcome}
TONE: {formal|sopan|tegas|persuasif}
BAHASA: {language}

POIN YANG HARUS DISAMPAIKAN:
1. {point_1}
2. {point_2}
3. {point_3}

BATASAN:
- Max 200 kata
- Subject line: actionable dan spesifik (max 8 kata)
- Opening: langsung ke konteks, bukan small talk
- Closing: clear call-to-action dengan deadline
- Jangan minta maaf berlebihan
- Hindari jargon yang tidak perlu

Output format:
Subject: [subject line]

[email body]

Expected Output:

Subject: Review dan Approval Q1 Budget Proposal

Bapak Direktur,

Mengikup diskusi 10 Januari, berikut proposal anggaran Q1 
untuk divisi Engineering yang memerlukan review dan 
approval Bapak sebelum 20 Januari.

Total pengajuan: Rp 2.4 miliar (peningkatan 12% dari Q4), 
dengan alokasi: infrastructure migration (40%), talent 
acquisition (35%), dan R&D tooling (25%). Detail lengkap 
terlampir.

Mohon konfirmasi jadwal review atau pertanyaan tambahan.

Hormat saya,
[Name]
Head of Engineering

Tips Adaptasi Template

  1. Mulai dengan template yang paling dekat dengan use case Anda
  2. Modifikasi few-shot examples dengan data real dari domain Anda
  3. Sesuaikan format output ke schema yang dibutuhkan sistem downstream
  4. Uji dengan minimal 20 contoh sebelum production deployment
  5. Iterasi berdasarkan failure cases — tambahkan instruksi khusus untuk kasus yang gagal
  6. Simpan versi yang bekerja sebagai baseline sebelum eksperimen
