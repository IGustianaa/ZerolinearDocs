Overview Tech Stack

Membangun aplikasi AI memerlukan stack teknologi yang tepat di setiap lapisan. Pilihan stack mempengaruhi kecepatan development, performa, scalability, dan maintainability. Berikut panduan mendalam untuk setiap lapisan.

Frontend

React / Next.js

React adalah library UI paling populer. Next.js menambahkan SSR, routing, dan optimisasi. Pilihan default untuk aplikasi web modern.

// Next.js dengan AI streaming
'use client';
import { useState } from 'react';

export default function ChatPage() {
 const [messages, setMessages] = useState([]);
 const [input, setInput] = useState('');

 async function send() {
 const res = await fetch('/api/chat', {
 method: 'POST',
 body: JSON.stringify({ message: input }),
 });
 const data = await res.json();
 setMessages([...messages, { user: input, ai: data.reply }]);
 setInput('');
 }

 return (
 <div>
 {messages.map((m, i) => (
 <div key={i}>
 <p>User: {m.user}</p>
 <p>AI: {m.ai}</p>
 </div>
 ))}
 <input value={input} onChange={e => setInput(e.target.value)} />
 <button onClick={send}>Send</button>
 </div>
 );
}

Kapan pakai: Aplikasi web kompleks, butuh SEO (Next.js), ekosistem matang, tim familiar React.

Vue / Nuxt

Vue menawarkan developer experience yang lebih halus dengan reactivity system yang intuitif. Nuxt adalah framework full-stack seperti Next.js.

<template>
 <div>
 <div v-for="msg in messages" :key="msg.id">
 <p>{{ msg.role }}: {{ msg.content }}</p>
 </div>
 <input v-model="input" @keyup.enter="send" />
 </div>
</template>

<script setup>
import { ref } from 'vue';
const messages = ref([]);
const input = ref('');
async function send() {
 const res = await fetch('/api/chat', {
 method: 'POST', body: JSON.stringify({ message: input.value })
 });
 const data = await res.json();
 messages.value.push({ role: 'user', content: input.value });
 messages.value.push({ role: 'ai', content: data.reply });
 input.value = '';
}
</script>

Kapan pakai: Prefer sintaks yang clean, tim kecil, butuh reactivity yang simpel.

Svelte / SvelteKit

Svelte adalah compiler, bukan runtime. Bundle size kecil, performance tinggi. SvelteKit adalah framework full-stack.

<script>
 let messages = [];
 let input = '';
 async function send() {
 const res = await fetch('/api/chat', {
 method: 'POST', body: JSON.stringify({ message: input })
 });
 const data = await res.json();
 messages = [...messages, { role: 'user', content: input }, { role: 'ai', content: data.reply }];
 input = '';
 }
</script>

{#each messages as msg}
 <p>{msg.role}: {msg.content}</p>
{/each}
<input bind:value={input} on:keydown={(e) => e.key === 'Enter' && send()} />

Kapan pakai: Performance critical, bundle size kecil, prefer simplicity.

Astro

Astro fokus pada content-driven site dengan partial hydration. Cocok untuk blog, dokumentasi, landing page.

Kapan pakai: Content site, blog, dokumentasi. Tidak untuk aplikasi interaktif kompleks.

Tailwind CSS

Utility-first CSS framework. Bukan framework UI tetapi memungkinkan styling cepat tanpa context switching.

// Tailwind dengan React
<button className="bg-yellow-500 hover:bg-yellow-600 text-white font-bold py-2 px-4 rounded-lg transition-colors">
 Send
</button>

Kapan pakai: Semua project. Tailwind cocok dengan AI coding karena utility class adalah pattern yang konsisten dan mudah dipelajari model.

Backend

Python (FastAPI)

Python adalah bahasa paling populer untuk AI karena ekosistem library (LangChain, transformers, openai). FastAPI menawarkan performance tinggi dengan type hints.

from fastapi import FastAPI
from pydantic import BaseModel
from openai import OpenAI

app = FastAPI()
client = OpenAI(api_key="...", base_url="http://localhost:20128/v1")

class ChatRequest(BaseModel):
 message: str
 model: str = "bai/minimax-m3"

@app.post("/api/chat")
async def chat(req: ChatRequest):
 response = client.chat.completions.create(
 model=req.model,
 messages=[{"role": "user", "content": req.message}],
 )
 return {"reply": response.choices[0].message.content}

@app.get("/health")
async def health():
 return {"status": "ok"}

Kapan pakai: AI-heavy backend, butuh Python library (NumPy, Pandas, scikit-learn), tim Python.

Node.js (Express / Fastify)

Node.js cocok untuk aplikasi real-time (WebSocket, streaming) dan full-stack JavaScript.

import Fastify from 'fastify';
import OpenAI from 'openai';

const fastify = Fastify({ logger: true });
const client = new OpenAI({ apiKey: '...', baseURL: 'http://localhost:20128/v1' });

fastify.post('/api/chat', async (request, reply) => {
 const { message, model = 'bai/minimax-m3' } = request.body;
 const response = await client.chat.completions.create({
 model,
 messages: [{ role: 'user', content: message }],
 stream: true,
 });
 
 reply.raw.setHeader('Content-Type', 'text/event-stream');
 for await (const chunk of response) {
 const text = chunk.choices[0]?.delta?.content || '';
 reply.raw.write(`data: ${JSON.stringify({ text })}

`);
 }
 reply.raw.end();
});

await fastify.listen({ port: 3000 });

Kapan pakai: Real-time app, streaming response, full-stack JS, tim JavaScript.

Go

Go unggul untuk microservice dengan throughput tinggi dan concurrency native.

package main

import (
 "encoding/json"
 "net/http"
 "bytes"
 "io"
)

func chatHandler(w http.ResponseWriter, r *http.Request) {
 var req struct {
 Message string `json:"message"`
 }
 json.NewDecoder(r.Body).Decode(&req)
 
 body, _ := json.Marshal(map[string]interface{}{
 "model": "bai/minimax-m3",
 "messages": []map[string]string{
 {"role": "user", "content": req.Message},
 },
 })
 
 resp, _ := http.Post(
 "http://localhost:20128/v1/chat/completions",
 "application/json",
 bytes.NewBuffer(body),
 )
 defer resp.Body.Close()
 
 w.Header().Set("Content-Type", "application/json")
 io.Copy(w, resp.Body)
}

func main() {
 http.HandleFunc("/api/chat", chatHandler)
 http.ListenAndServe(":8080", nil)
}

Kapan pakai: High-throughput microservice, CLI tool, infrastruktur.

Rust untuk performance critical dan system programming. Axum adalah web framework populer.

Kapan pakai: Performance critical, system tool, WebAssembly. Learning curve tinggi.

Database

PostgreSQL

Database relasional pilihan untuk produksi. Mendukung pgvector untuk vector search (RAG).

-- Enable pgvector
CREATE EXTENSION vector;

-- Table untuk document embeddings
CREATE TABLE documents (
 id SERIAL PRIMARY KEY,
 content TEXT,
 embedding VECTOR(1536),
 metadata JSONB
);

-- Index untuk vector search
CREATE INDEX ON documents USING ivfflat (embedding vector_cosine_ops);

-- Vector search (RAG)
SELECT content, metadata
FROM documents
ORDER BY embedding <=> '[0.1, 0.2, ...]'::vector
LIMIT 5;

Kapan pakai: Data terstruktur, RAG dengan pgvector, transactional app.

Redis

In-memory store untuk caching, rate limiting, dan session management.

import redis
r = redis.Redis(host='localhost', port=6379, db=0)

# Cache LLM response
def get_cached_response(query):
 cached = r.get(f"llm:{hash(query)}")
 if cached:
 return cached.decode()
 
 response = call_llm(query)
 r.setex(f"llm:{hash(query)}", 3600, response) # TTL 1 jam
 return response

# Rate limiting
def check_rate_limit(user_id):
 key = f"rate:{user_id}"
 count = r.incr(key)
 if count == 1:
 r.expire(key, 60) # Window 1 menit
 return count <= 60 # 60 request/menit

Kapan pakai: Caching, rate limiting, session, queue, pub/sub.

Vector Database

Untuk RAG dan semantic search. Pilihan: Pinecone (managed), Weaviate (self-host), Qdrant (Rust-based, cepat).

# Qdrant untuk RAG
from qdrant_client import QdrantClient
from openai import OpenAI

qdrant = QdrantClient(host="localhost", port=6333)
client = OpenAI(api_key="...")

# Store document
def store_document(text, metadata):
 embedding = client.embeddings.create(
 model="text-embedding-3-small",
 input=text,
 ).data[0].embedding
 
 qdrant.upsert(
 collection_name="docs",
 points=[{
 "id": hash(text),
 "vector": embedding,
 "payload": {"text": text, **metadata}
 }]
 )

# Search
def search_documents(query, limit=5):
 embedding = client.embeddings.create(
 model="text-embedding-3-small",
 input=query,
 ).data[0].embedding
 
 results = qdrant.search(
 collection_name="docs",
 query_vector=embedding,
 limit=limit,
 )
 return [r.payload for r in results]

Kapan pakai: RAG, semantic search, recommendation system.

AI Layer

LangChain / LangGraph

Framework untuk membangun LLM application dengan chain, agent, dan memory.

from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

llm = ChatOpenAI(
 model="bai/minimax-m3",
 base_url="http://localhost:20128/v1",
 api_key="...",
)

prompt = ChatPromptTemplate.from_messages([
 ("system", "Anda asisten coding yang expert."),
 ("user", "{input}"),
])

chain = prompt | llm | StrOutputParser()
result = chain.invoke({"input": "Jelaskan async/await di Python"})

9Router (Self-hosted Gateway)

Gateway yang menyatukan multiple LLM provider dengan combo, fallback, dan token saver.

vLLM (Inference Server)

High-throughput inference untuk model open-weight. Mendukung PagedAttention.

# Serve Llama 3.1 70B dengan vLLM
python -m vllm.entrypoints.openai.api_server --model meta-llama/Llama-3.1-70B-Instruct --port 8000 --tensor-parallel-size 2

# Sekarang tersedia di http://localhost:8000/v1/chat/completions

LiteLLM

Proxy yang menyatukan 100+ LLM provider ke dalam satu API OpenAI-compatible.

import litellm

# Panggil model dari provider berbeda dengan API yang sama
response = litellm.completion(
 model="anthropic/claude-3.5-sonnet",
 messages=[{"role": "user", "content": "Hello"}],
)

DevOps

Docker

Containerization untuk deployment yang konsisten.

# Dockerfile untuk AI app
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 8000
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
