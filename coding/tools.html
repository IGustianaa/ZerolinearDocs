Lanskap AI Coding Tools

Tool AI coding dibagi menjadi tiga kategori: IDE AI-native, extension/plugin, dan CLI agent. Setiap kategori memiliki trade-off antara integrasi, kontrol, dan otonomi.

Cursor

Cursor adalah IDE AI-native berbasis VS Code fork. Dibangun dari awal dengan AI sebagai inti, bukan tambangan belakangan.

Fitur unggulan Cursor:

  1. Codebase context — Cursor mengindex seluruh project dan dapat menjawab pertanyaan tentang kode di file mana pun. Tidak terbatas pada file aktif.
  2. Inline edit (Cmd+K) — Pilih blok kode, ketik instruksi natural language, AI mengedit langsung. Diff view menunjukkan perubahan sebelum diapply.
  3. Composer — Multi-file edit simultan. AI dapat mengubah 5+ file sekaligus dengan konsistensi. Ideal untuk refactoring besar.
  4. Agent mode — AI dapat menjalankan command, membaca output, dan iterate. Autonomous problem-solving.
  5. Model selection — Pilih model backend: Claude 3.5 Sonnet (terbaik untuk kode), GPT-4o, atau model lain. Bisa pakai API key sendiri.
  6. Tab completion — Autocomplete yang tidak hanya melengkapi baris, tetapi menebak niat dan melengkapi seluruh blok logika.
  7. @-mentions — Reference file, symbol, atau doc spesifik dalam chat. @utils.py, @schema, @docs.

Setup:

# Download Cursor
# macOS: brew install --cask cursor
# Linux/Windows: Download dari cursor.com

# Buka project
cursor ./my-project

# Pilih model di Settings > Models
# Recommended: Claude 3.5 Sonnet untuk coding

GitHub Copilot

Plugin AI untuk VS Code, JetBrains, dan Neovim. Produk pertama yang mempopulerkan AI coding.

Fitur:

  1. Inline completion — Ghost text suggestion berbasis konteks file aktif dan file terkait
  2. Copilot Chat — Chat panel untuk pertanyaan tentang kode, debugging, penjelasan
  3. Copilot CLI — gh copilot untuk command-line assistance
  4. Copilot Workspace — Planned: autonomous issue resolution

Setup:

# Install di VS Code
# 1. Buka Extensions (Ctrl+Shift+X)
# 2. Search "GitHub Copilot"
# 3. Install dan sign in dengan GitHub account
# 4. Subscription: $10/bulan atau free untuk student/OSS

# CLI
gh extension install github/gh-copilot
gh copilot suggest "git command to undo last commit"

Windsurf (Codeium)

IDE AI-native dari Codeium, kompetitor langsung Cursor. Fokus pada "flow state" dengan AI agent yang proaktif.

Fitur:

  1. Cascade — Multi-step AI agent yang dapat menjalankan urutan tindakan: baca kode, tulis kode, jalankan test, perbaiki error
  2. Superautocomplete — Completion yang lebih agresif dari Copilot, menekap hingga 20+ baris
  3. Codebase indexing — Full project context untuk chat dan completion
  4. Flow mode — AI proaktif menyarankan perbaikan dan improvement tanpa diminta

Setup:

# Download dari codeium.com/windsurf
# Tersedia untuk macOS, Linux, Windows
# Free tier tersedia dengan batasan

Claude Code

CLI agent dari Anthropic yang berjalan di terminal. Agent-based: dapat menjalankan command, edit file, dan iterate hingga task selesai.

Fitur:

  1. Terminal-native — Tidak butuh IDE. Bekerja di terminal mana pun.
  2. Filesystem access — Dapat membaca, menulis, dan mencari file di project
  3. Shell execution — Menjalankan command (npm test, git, build) dan membaca output
  4. Iterative — Jika ada error, AI memperbaiki dan mencoba lagi
  5. Tool use — Dapat memanggil API, query database, dan melakukan network request

CLI example:

# Install
npm install -g @anthropic-ai/claude-code

# Run di project directory
cd my-project
claude-code

# Interactive mode
> "Add user authentication with JWT. Create middleware,
 update routes, and write tests."

# Claude Code akan:
# 1. Membaca package.json dan struktur project
# 2. Install jsonwebtoken dependency
# 3. Membuat auth middleware
# 4. Update route files
# 5. Menulis test files
# 6. Run npm test
# 7. Fix errors if any
# 8. Report completion dengan summary

# One-shot mode
claude-code --task "Fix the failing test in auth.test.js"

OpenAI Codex

CLI agent dari OpenAI, konsep serupa dengan Claude Code tetapi menggunakan model OpenAI (GPT-4o, o1, o3-mini).

CLI example:

# Install
npm install -g @openai/codex

# Run
cd my-project
codex

# Interactive
> "Refactor the database layer to use connection pooling"

# Codex akan:
# 1. Analyze current database code
# 2. Identify connection patterns
# 3. Implement pooling
# 4. Update all queries
# 5. Run tests
# 6. Create commit

# Dengan model tertentu
codex --model o3-mini --task "Optimize the React render performance"

Hermes Agent (Coding via Skills)

Hermes Agent adalah framework yang mendukung coding melalui skill system. Skill adalah knowledge base yang dimuat saat dibutuhkan, memberi agen prosedur dan konvensi coding.

Fitur coding Hermes:

  1. Coding skill — Skill berisi best practice, convention, dan prosedur untuk project spesifik
  2. Plugin tools — Plugin untuk akses filesystem, shell, dan code execution
  3. Multi-profile — Profil terpisah untuk project berbeda dengan skill dan config sendiri
  4. Cron jobs — Scheduled code review atau test runner
  5. Delegation — Spawn subagent untuk task kompleks (mis. satu untuk backend, satu untuk frontend)

Setup coding dengan Hermes:

# Install Hermes
npm install -g hermes-agent
hermes setup

# Untuk skill untuk coding convention
cat > ~/.hermes/profiles/default/skills/coding-convention.md << 'EOF'
---
name: Coding Convention
description: Convention dan best practice untuk project ini
trigger: ketika user minta coding, refactoring, atau code review
---
## Convention
- Gunakan TypeScript strict mode
- Naming: camelCase untuk variabel, PascalCase untuk class
- Error handling: selalu try-catch dengan logger
- Test coverage minimum 80%
- Tidak ada `any` type
EOF

# Hermes akan otomatis load skill ini saat task coding
hermes chat
> "Buatkan REST API untuk todo app dengan TypeScript"
# Hermes load coding skill, generate code sesuai convention

Panduan Setup per Tool

Cursor

  1. Download dari cursor.com
  2. Sign in (Google atau email)
  3. Pilih model: Settings > Models > Claude 3.5 Sonnet
  4. Buka project: cursor ./project
  5. Mulai dengan Cmd+K untuk inline edit

Copilot

  1. Install extension di VS Code
  2. Sign in dengan GitHub
  3. Aktifkan subscription
  4. Mulai mengetik, ghost text akan muncul
  5. Tekan Tab untuk accept

Hermes Agent

  1. npm install -g hermes-agent && hermes setup
  2. Edit ~/.hermes/config.yaml dengan provider
  3. Untuk skill untuk convention project
  4. hermes chat untuk mulai coding

Pemilihan tool bergantung pada workflow: untuk GUI preferensi, Cursor atau Windsurf. Untuk terminal, Claude Code atau Codex. Untuk automation dan kontrol penuh, Hermes Agent.
