Mengapa Framework

Membangun agen AI dari nol memerlukan implementasi reasoning loop, tool orchestration, state management, error handling, dan memory — semuanya kompleks dan rawan bug. Framework menyediakan abstraksi siap pakai sehingga developer fokus pada logic bisnis, bukan infrastruktur. Pemilihan framework yang tepat menentukan kecepatan development, maintainability, dan kemampuan scaling.

LangGraph

LangGraph adalah framework dari LangChain yang memodelkan agen sebagai state graph — struktur berorientasi node dan edge di mana setiap node adalah fungsi (LLM call, tool execution, atau logic) dan setiap edge menentukan transisi. Kekuatan utama: kontrol alur yang eksplisit dan predictable.

Fitur kunci: cycles (loop yang diperlukan untuk reasoning loop), conditional routing (branch berdasarkan state), human-in-the-loop (pause untuk approval), checkpointing (persist state untuk resume), dan streaming (token-by-token output).

from langgraph.graph import StateGraph, END
from typing import TypedDict, Annotated
import operator

class AgentState(TypedDict):
 messages: Annotated[list, operator.add]

def call_model(state: AgentState):
 response = llm.invoke(state["messages"])
 return {"messages": [response]}

def should_continue(state: AgentState):
 last = state["messages"][-1]
 if last.tool_calls:
 return "tools"
 return END

# Build graph
workflow = StateGraph(AgentState)
workflow.add_node("agent", call_model)
workflow.add_node("tools", tool_node)
workflow.set_entry_point("agent")
workflow.add_conditional_edges("agent", should_continue)
workflow.add_edge("tools", "agent") # loop back

app = workflow.compile()
result = app.invoke({"messages": [human_msg("Summarize latest AI news")]})

LangGraph ideal untuk: pipeline kompleks dengan branch conditions, sistem yang butuh audit trail, dan aplikasi yang memerlukan checkpoint/resume. Kurva belajar agak curam tetapi kontrol yang diberikan setara.

CrewAI

CrewAI adalah framework berbasis peran yang memodelkan agen sebagai tim. Developer mendefinisikan crew (tim), setiap agen dengan role, goal, backstory, dan tools. Agen berkolaborasi melalui tasks yang didelegasikan secara berurutan atau hierarkis.

Filosofi: "agent as team member". Setiap agen memiliki persona yang mempengaruhi reasoning. CrewAI menangani orchestration, delegation, dan result aggregation.

from crewai import Agent, Task, Crew

researcher = Agent(
 role="Senior Research Analyst",
 goal="Find comprehensive information about {topic}",
 backstory="Expert analyst with 15 years experience in tech research.",
 tools=[search_tool, scrape_tool],
 llm="gpt-4o"
)

writer = Agent(
 role="Technical Writer",
 goal="Write a clear, engaging report based on research findings.",
 backstory="Award-winning writer specializing in tech documentation.",
 llm="claude-3-5-sonnet"
)

research_task = Task(
 description="Research {topic} and gather key findings.",
 agent=researcher,
 expected_output="Bullet list of 10 key findings with sources."
)

write_task = Task(
 description="Write a 2000-word report from the research findings.",
 agent=writer,
 expected_output="Markdown report with introduction, findings, conclusion.",
 context=[research_task] # depends on research output
)

crew = Crew(
 agents=[researcher, writer],
 tasks=[research_task, write_task],
 process=Process.sequential
)

result = crew.kickoff(inputs={"topic": "AI agents in 2025"})

CrewAI ideal untuk: content pipeline, workflow dengan peran jelas, dan tim yang ingin prototype multi-agent dengan cepat. Sangat developer-friendly dengan abstraksi tinggi.

AutoGen

AutoGen adalah framework Microsoft untuk multi-agent conversation. Agen berkomunikasi melalui percakapan natural language, bukan graph atau role definition. Setiap pesan dapat memicu respons dari agen lain, menciptakan dynamic interaction.

Fitur unik: code execution agent yang dapat menulis dan menjalankan kode Python dalam sandbox, group chat dengan manager agent yang memutuskan siapa bicara berikutnya, dan teachability (agen belajar dari feedback dalam percakapan).

from autogen import AssistantAgent, UserProxyAgent, GroupChat, GroupChatManager

# Code execution agent
coder = AssistantAgent(
 name="Coder",
 system_message="You are a Python developer. Write code to solve problems.",
 llm_config={"model": "gpt-4o"},
)

# Executor that runs code
executor = UserProxyAgent(
 name="Executor",
 human_input_mode="NEVER",
 code_execution_config={"work_dir": "workspace"},
)

# Reviewer that checks code quality
reviewer = AssistantAgent(
 name="Reviewer",
 system_message="Review code for bugs and security. Suggest improvements.",
 llm_config={"model": "claude-3-5-sonnet"},
)

group_chat = GroupChat(
 agents=[coder, executor, reviewer],
 messages=[],
 max_round=15,
)

manager = GroupChatManager(groupchat=group_chat)
executor.initiate_chat(manager, message="Build a REST API for todo app with FastAPI.")

AutoGen ideal untuk: software development multi-agent, eksperimen conversational AI, dan skenario di mana interaksi dinamis antar-agen lebih penting dari alur yang ditentukan.

Hermes Agent

Hermes Agent adalah framework oleh Nous Research yang fokus pada production readiness dengan fitur:

  • Profile system — Setiap agen berjalan dalam profil terpisah dengan skills, plugins, cron, dan memories sendiri. Memungkinkan satu instalasi menjalankan multiple agen independen.
  • Plugin architecture — Tools dan capabilities dapat ditambahkan sebagai plugin tanpa mengubah core. Plugin dapat berisi skill definitions, command handlers, dan tool schemas.
  • Cron scheduling — Agen dapat menjalankan task terjadwal tanpa supervisor. Ideal untuk monitoring, digest, dan batch processing.
  • Memory persistence — Long-term memory yang tersimpan antar-sesi, dengan semantic retrieval.
  • Multi-provider support — Integrasi native dengan 9Router untuk failover otomatis antar LLM vendor.
  • Guardrails — Max iterations, tool whitelist, dan human-in-the-loop approval.

OpenAI Swarm

OpenAI Swarm adalah framework eksperimental yang sangat lightweight, fokus pada agent handoff. Konsep: agen dapat mendelegasikan ke agen lain dengan konteks penuh. Swarm tidak memiliki state manager eksplisit — state di-pass sebagai parameter antar fungsi. Cocok untuk prototyping cepat tetapi kurang untuk production complex.

Kriteria Pemilihan Framework

  1. Complexity of workflow — Pipeline dengan banyak branch dan condition? LangGraph. Linear dengan peran? CrewAI. Dynamic conversation? AutoGen.
  2. Production readiness — Butuh persistence, cron, multi-profile? Hermes Agent. Prototyping cepat? Swarm atau CrewAI.
  3. Multi-agent necessity — Jika ya, CrewAI atau AutoGen. Jika single-agent cukup, LangGraph atau Hermes.
  4. Code execution — AutoGen memiliki built-in sandbox. Framework lain butuh integrasi manual.
  5. Ecosystem — LangGraph memiliki integrasi terluas (LangChain ecosystem). Hermes memiliki 9Router integration.
  6. Team expertise — Tim Python beginner? CrewAI paling ramah. Tim advanced yang butuh kontrol penuh? LangGraph.

Tidak ada framework "terbaik" secara absolut. Pilih berdasarkan kebutuhan tugas, maturity yang dibutuhkan, dan ekosistem yang ingin diintegrasikan. Banyak tim production menggunakan kombinasi: LangGraph untuk core logic, CrewAI untuk content pipeline, Hermes untuk autonomous monitoring.
