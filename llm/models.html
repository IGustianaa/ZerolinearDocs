Kriteria Pemilihan Model

Pemilihan model LLM adalah keputusan multi-dimensional. Lima faktor utama harus dipertimbangkan secara bersamaan: cost (biaya per token), speed (latency per request), quality (kualitas output pada task Anda), context window (kapasitas input), dan ecosystem (tool calling, fine-tuning, deployment options). Tidak ada model yang optimal di semua dimensi — selalu ada trade-off.

Contoh Kalkulasi Biaya

Aplikasi chatbot dengan rata-rata 500 token input + 200 token output per conversation, 10.000 conversation per hari:

  • GPT-4o-mini: (500 × $0.15 + 200 × $0.60) / 1M × 10.000 = $0.195 × 10 = $1.95/hari = $58.50/bulan
  • GPT-4o: (500 × $2.50 + 200 × $10.00) / 1M × 10.000 = $3.25 × 10 = $32.50/hari = $975/bulan
  • Claude 3.5 Sonnet: (500 × $3.00 + 200 × $15.00) / 1M × 10.000 = $4.50 × 10 = $45.00/hari = $1.350/bulan
  • DeepSeek V3: (500 × $0.14 + 200 × $0.28) / 1M × 10.000 = $0.126 × 10 = $1.26/hari = $37.80/bulan

Selisih 36x antara DeepSeek ($37.80/bulan) dan Claude Sonnet ($1.350/bulan). Jika kualitas DeepSeek cukup untuk use case, penghematan signifikan.

Self-Host vs API

Kapan Self-Host (Open Weight)

  • Privacy absolute — Data sensitif (healthcare, finance, military) tidak boleh keluar infrastruktur
  • High volume — Jika biaya API > biaya infrastruktur GPU. Break-even: ~50M+ token per bulan
  • Customization — Butuh fine-tuning dengan data proprietary
  • Latency control — Self-host menghilangkan network latency ke vendor
  • No vendor lock-in — Tidak tergantung pricing change atau deprecation

Kapan API (Managed)

  • Low volume — Biaya infrastruktur GPU > biaya API. Under 10M token/bulan, API selalu lebih murah
  • Prototyping — Cepat, tanpa setup GPU
  • Frontier quality — Model proprietary (GPT-4o, Claude) tidak tersedia open weight
  • No DevOps burden — Vendor menangani scaling, uptime, security patches
  • Managed features — Function calling, vision, fine-tuning API

Perhitungan Break-Even

Self-hosting Llama 3.1 70B dengan quantization INT4:

  • GPU: 1x A100 80GB = ~$2/juta (dedicated) atau ~$0.80/jam (spot)
  • Throughput: ~50 token/detik
  • Token per bulan: 50 × 86400 × 30 = ~129M token (max capacity)
  • Biaya GPU: $1.440/bulan (dedicated) atau $576/bulan (spot)

API equivalent (DeepSeek V3):

  • 129M token input: 129 × $0.14 = $18.06/bulan
  • 129M token output: 129 × $0.28 = $36.12/bulan
  • Total: ~$54/bulan

Kesimpulan: untuk volume di bawah ~300M token/bulan, API jauh lebih murah. Self-hosting baru viable di atas volume itu atau jika privacy requirement mandatory.

Cost Calculation Example

Skenario: SaaS startup dengan 1.000 active user, masing-masing 50 query/hari, rata-rata 300 token input + 100 token output per query.

Daily tokens: 1.000 × 50 × (300 + 100) = 20M token/hari = 600M token/bulan.

Strategi optimal: model tiering via 9Router

  • 80% query (simple) -> GPT-4o-mini: 480M × ($0.15×0.75 + $0.60×0.25)/1M = 480M × $0.2625/1M = $126/bulan
  • 20% query (complex) -> Claude Sonnet: 120M × ($3.00×0.75 + $15.00×0.25)/1M = 120M × $5.625/1M = $675/bulan
  • Total: ~$801/bulan

vs all Claude Sonnet: 600M × $5.625/1M = $3.375/bulan (4.2x lebih mahal)

vs all GPT-4o-mini: 600M × $0.2625/1M = $157.50/bulan (tapi kualitas tidak cukup untuk 20% complex query)

Model tiering menghemat ~76% dibanding all-premium, sambil menjaga kualitas untuk task yang membutuhkannya. Ini adalah strategi yang harus dipertimbangkan setiap production deployment.

Pemilihan model bukan keputusan satu kali. Setup A/B testing framework, monitor quality dan cost secara berkelanjutan, dan re-evaluasi setiap quarter saat model baru rilis dan pricing berubah.
