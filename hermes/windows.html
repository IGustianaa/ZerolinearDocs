Prasyarat

  • Windows 10/11 (64-bit)
  • WSL2 (Windows Subsystem for Linux) atau Node.js native
  • 8GB+ RAM (recommended)
  • Koneksi internet stabil

WSL2 Setup

WSL2 memberikan environment Linux lengkap di Windows, cocok untuk Hermes dan 9Router.

Install WSL2

# Buka PowerShell sebagai Administrator
wsl --install -d Ubuntu

# Restart komputer jika diminta
# Setelah restart, Ubuntu akan launch dan minta username/password

# Di Ubuntu WSL:
sudo apt update && sudo apt upgrade -y
sudo apt install -y nodejs npm curl git nano

Install Node.js di WSL (Recommended: NodeSource)

# Versi Ubuntu repository mungkin outdated
# Gunakan NodeSource untuk Node.js 20 LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# Verify
node --version # v20.x.x
npm --version # v10.x.x

Install Hermes di WSL

# Install Hermes
npm install -g hermes-agent

# Setup
hermes setup

# Edit config
nano ~/.hermes/config.yaml

Install 9Router di WSL

npm install -g 9router
9r # Start di port 20128

Windows Native (Tanpa WSL)

Jika tidak ingin menggunakan WSL, Hermes dapat berjalan di Windows native dengan Node.js.

Install Node.js

# Download dari nodejs.org (LTS version)
# Atau via winget:
winget install OpenJS.NodeJS.LTS

# Verify
node --version
npm --version

Install Hermes

# Install Hermes
npm install -g hermes-agent

# Setup
hermes setup

# Config akan di:
# C:\Users\<username>\.hermes\config.yaml

Install 9Router

npm install -g 9router
9r # Start di port 20128

9Router on Windows

9Router berjalan sama di Windows dan WSL. Dashboard tersedia di http://localhost:20128.

# Start 9Router
9r

# Background (PowerShell)
Start-Process -NoNewWindow 9r

# Atau job
Start-Job -ScriptBlock { 9r }

Config Paths

WSL2

~/.hermes/config.yaml # Hermes config
~/.hermes/profiles/ # Profiles
~/.9router/ # 9Router data
~/.9router/db/data.sqlite # 9Router database

Dalam Windows Explorer, path WSL dapat diakses di:

\\wsl$\Ubuntu\home\<username>\.hermes\
\\wsl$\Ubuntu\home\<username>\.9router\

Windows Native

C:\Users\<username>\.hermes\config.yaml
C:\Users\<username>\.hermes\profiles\
C:\Users\<username>\.9router\
C:\Users\<username>\.9router\db\data.sqlite

Environment variables di Windows:

# Set environment variable (permanent)
[System.Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "sk-...", "User")
[System.Environment]::SetEnvironmentVariable("TELEGRAM_BOT_TOKEN", "123:ABC...", "User")

# Restart terminal setelah set env var

Docker Alternative

Docker memberikan isolation dan portability. Cocok jika sudah familiar dengan Docker.

Dockerfile

FROM node:20-slim

# Install Hermes dan 9Router
RUN npm install -g hermes-agent 9router

# Setup directories
RUN mkdir -p /root/.hermes /root/.9router
WORKDIR /root

# Copy config
COPY config.yaml /root/.hermes/config.yaml

# Expose port
EXPOSE 20128

# Start script
COPY start.sh /start.sh
RUN chmod +x /start.sh
CMD ["/start.sh"]

start.sh

#!/bin/bash
# Start 9Router
nohup 9r > /root/.9router/9router.log 2>&1 &
sleep 3

# Start Hermes
hermes gateway start

docker-compose.yml

version: '3.8'
services:
 hermes:
 build: .
 container_name: hermes-agent
 ports:
 - "20128:20128"
 volumes:
 - hermes-data:/root/.hermes
 - 9router-data:/root/.9router
 environment:
 - TELEGRAM_BOT_TOKEN=${TELEGRAM_BOT_TOKEN}
 - OPENAI_API_KEY=${OPENAI_API_KEY}
 restart: unless-stopped

volumes:
 hermes-data:
 9router-data:

Run dengan Docker

# Build dan run
docker-compose up -d

# Cek logs
docker-compose logs -f hermes

# Stop
docker-compose down

Recommended Setup

Untuk pengguna Windows, recommended setup:

  1. WSL2 + Ubuntu untuk environment Linux yang konsisten
  2. Node.js 20 LTS via NodeSource
  3. 9Router sebagai gateway di localhost:20128
  4. Hermes Agent dengan provider custom:9router
  5. Telegram bot sebagai interface utama
  6. Docker untuk deployment ke server produksi

Auto-Start pada Boot

Windows Task Scheduler

Set Hermes dan 9Router untuk start otomatis saat Windows boot:

# Untuk script startup
@echo off
echo Starting 9Router...
start /B cmd /c "9r > %USERPROFILE%\.9router\9router.log 2>&1"
timeout /t 3 /nobreak >nul
echo Starting Hermes...
start /B cmd /c "hermes gateway start > %USERPROFILE%\.hermes\logs\gateway.log 2>&1"
echo Services started.

# Simpan sebagai start-hermes.bat
# Buka Task Scheduler
# Create Task:
# - Name: Hermes Agent
# - Trigger: At log on
# - Action: Start a program -> start-hermes.bat
# - Conditions: Start only if network connection available

WSL2 Auto-Start

# Di WSL, tambahkan ke ~/.bashrc atau untuk startup script
cat > ~/start-services.sh << 'EOF'
#!/bin/bash
# Start 9Router if not running
if ! pgrep -f "9r" > /dev/null; then
 nohup 9r > ~/.9router/9router.log 2>&1 &
fi
sleep 2
# Start Hermes gateway if not running
if ! pgrep -f "hermes gateway" > /dev/null; then
 nohup hermes gateway start > ~/.hermes/logs/gateway.log 2>&1 &
fi
EOF

chmod +x ~/start-services.sh
# Tambahkan ke ~/.bashrc
echo '~/start-services.sh' >> ~/.bashrc

Performance Tuning

WSL2 Memory Limit

WSL2 default menggunakan hingga 50% RAM sistem. Batasi untuk mencegah OOM:

# Windows: C:\Users\<username>\.wslconfig
[wsl2]
memory=4GB
processors=4
swap=2GB

Restart WSL setelah perubahan: wsl --shutdown lalu buka kembali.

Node.js Optimization

# Set memory limit untuk Node.js
export NODE_OPTIONS="--max-old-space-size=1024"

# Untuk Hermes dengan banyak plugin
export NODE_OPTIONS="--max-old-space-size=2048"

# Tambahkan ke ~/.bashrc atau startup script
echo 'export NODE_OPTIONS="--max-old-space-size=1024"' >> ~/.bashrc

Windows Defender Exclusion

Tambahkan folder Hermes dan 9Router ke exclusion Windows Defender untuk performance:

# Run as Administrator
Add-MpPreference -ExclusionPath "$env:USERPROFILE\.hermes"
Add-MpPreference -ExclusionPath "$env:USERPROFILE\.9router"
Add-MpPreference -ExclusionPath "$env:APPDATA\npm"

Dengan setup yang benar, Hermes di Windows dapat berjalan stabil 24/7, baik via WSL2 maupun native. WSL2 memberikan experience paling dekat dengan Linux production environment, sementara Docker memberikan isolation maksimum untuk deployment.
