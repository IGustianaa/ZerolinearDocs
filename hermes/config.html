config.yaml Full Reference

File ~/.hermes/config.yaml adalah pusat konfigurasi Hermes. Berikut referensi lengkap setiap section:

# ============================================
# COMPLETE CONFIG REFERENCE
# ============================================

# --- Model ---
model:
 default: "bai/minimax-m3" # Model ID default
 provider: "custom:9router" # Provider: openai, anthropic, google, custom:{name}
 # Jika pakai provider built-in:
 # provider: "openai"
 # api_key: "${OPENAI_API_KEY}"
 # base_url: "https://api.openai.com/v1" # optional override

# --- Custom Providers ---
# Multiple provider dapat didefinisikan
custom_providers:
 9router:
 base_url: "http://localhost:20128/v1"
 api_key: "9r-sk-your-key"
 models: # Daftar model yang tersedia
 - "nvidia/z-ai/glm-5.2"
 - "aiand/zai-org/glm-5.2"
 - "bai/minimax-m3"
 - "deepseek/deepseek-chat-v4"

 openrouter:
 base_url: "https://openrouter.ai/api/v1"
 api_key: "${OPENROUTER_API_KEY}"
 models:
 - "openai/gpt-4o"
 - "anthropic/claude-3.5-sonnet"
 - "google/gemini-1.5-pro"

 local-ollama:
 base_url: "http://localhost:11434/v1"
 api_key: "ollama"
 models:
 - "llama3.1:70b"
 - "mistral:7b"

# --- Fallback Providers ---
# Dicoba berurutan jika primary gagal
fallback_providers:
 - provider: "custom:openrouter"
 model: "openai/gpt-4o-mini"
 condition: "timeout" # timeout, error, rate_limit, all
 - provider: "custom:local-ollama"
 model: "llama3.1:70b"
 condition: "all" # Fallback untuk semua error

# --- Profile ---
active_profile: "default" # Profile aktif
# Untuk profile: hermes profile create <name>
# Switch: hermes profile switch <name>

# --- Agent Settings ---
max_tokens: 4096 # Max output token
temperature: 0.7 # 0.0=deterministic, 1.0=creative
top_p: 1.0 # Nucleus sampling
stream: true # Stream response

# --- System Prompt ---
system_prompt: |
 Anda adalah Hermes Agent.
 Gunakan tools untuk menyelesaikan tugas.
 Berikan respons yang akurat dan efisien.

# --- Gateway ---
gateway:
 telegram:
 enabled: true
 bot_token: "${TELEGRAM_BOT_TOKEN}"
 allowed_users: ["123456789"]
 command_prefix: "/" # Prefix untuk command
 
 discord:
 enabled: false
 bot_token: "${DISCORD_BOT_TOKEN}"
 allowed_channels: ["channel-id"]

# --- Memory ---
memory:
 enabled: true
 max_entries: 1000 # Max memory entries
 auto_save: true # Auto-save conversation facts

# --- Tools ---
tools:
 terminal:
 enabled: true
 timeout: 30 # Command timeout (seconds)
 filesystem:
 enabled: true
 allowed_paths: ["~", "/tmp"] # Restrict access
 network:
 enabled: true
 timeout: 10
 code_execution:
 enabled: true
 sandbox: true # Run in sandbox
 vision:
 enabled: false # Enable jika butuh image analysis

# --- Logging ---
logging:
 level: "info" # debug, info, warn, error
 file: "~/.hermes/logs/hermes.log"
 max_size: "10MB" # Rotate when exceed
 max_files: 5 # Keep N rotated files

# --- Delegation ---
delegation:
 enabled: true
 max_subagents: 3 # Max concurrent subagents
 subagent_timeout: 300 # Seconds

Custom Providers: Multiple Examples

Contoh 1: 9Router dengan Combo

custom_providers:
 9router:
 base_url: "http://localhost:20128/v1"
 api_key: "9r-sk-xxxxx"
 models:
 # Combo names (lihat halaman combo.html)
 - "Skil1Ulti" # Combo: rotasi 5 model
 - "Skil1Hemat" # Combo: model hemat
 # Individual models
 - "nvidia/z-ai/glm-5.2"
 - "bai/minimax-m3"

Contoh 2: Multi-Provider tanpa Gateway

custom_providers:
 openai:
 base_url: "https://api.openai.com/v1"
 api_key: "${OPENAI_API_KEY}"
 models: ["gpt-4o", "gpt-4o-mini"]

 anthropic:
 base_url: "https://api.anthropic.com/v1"
 api_key: "${ANTHROPIC_API_KEY}"
 models: ["claude-3-5-sonnet", "claude-3-haiku"]

 together:
 base_url: "https://api.together.xyz/v1"
 api_key: "${TOGETHER_API_KEY}"
 models: ["meta-llama/Llama-3.1-70B-Instruct-Turbo"]

Contoh 3: Local + Cloud Hybrid

custom_providers:
 local:
 base_url: "http://localhost:11434/v1"
 api_key: "ollama"
 models: ["llama3.1:70b", "qwen2.5:32b"]

 cloud:
 base_url: "https://api.openai.com/v1"
 api_key: "${OPENAI_API_KEY}"
 models: ["gpt-4o", "gpt-4o-mini"]

model:
 default: "llama3.1:70b"
 provider: "custom:local" # Default: local (free)

fallback_providers: # Fallback: cloud jika local down
 - provider: "custom:cloud"
 model: "gpt-4o-mini"
 condition: "all"

Fallback Providers

Fallback chain dicoba berurutan saat primary gagal:

fallback_providers:
 # Priority 1: Coba provider lain dengan model sama
 - provider: "custom:openrouter"
 model: "openai/gpt-4o-mini"
 condition: "rate_limit" # Hanya saat rate limit

 # Priority 2: Coba model lokal
 - provider: "custom:local"
 model: "llama3.1:70b"
 condition: "all" # Semua jenis error

 # Priority 3: Coba provider lebih murah
 - provider: "custom:9router"
 model: "bai/minimax-m3"
 condition: "timeout" # Hanya saat timeout

Model ID Format Rules

Di 9Router, model ID wajib menggunakan prefix nama provider:

FormatStatusKeterangan
nvidia/z-ai/glm-5.2ValidProvider nvidia, model z-ai/glm-5.2
aiand/zai-org/glm-5.2ValidProvider aiand, model zai-org/glm-5.2
bai/minimax-m3ValidProvider bai, model minimax-m3
deepseek/deepseek-chat-v4ValidProvider deepseek, model deepseek-chat-v4
z-ai/glm-5.2ERRORTidak ada prefix provider
glm-5.2ERRORTidak ada prefix provider
Skil1UltiValidCombo name (tanpa prefix, diakui khusus)

9Router Integration Config

Konfigurasi lengkap untuk integrasi Hermes + 9Router:

# config.yaml
model:
 default: "Skil1Ulti" # Pakai combo sebagai default
 provider: "custom:9router"

custom_providers:
 9router:
 base_url: "http://localhost:20128/v1"
 api_key: "9r-sk-your-api-key"
 models:
 # Combos
 - "Skil1Ulti" # Rotasi 5 model premium
 - "Skil1Hemat" # Rotasi model hemat
 - "Skil1Backup" # Fallback chain
 # Individual models
 - "nvidia/z-ai/glm-5.2"
 - "aiand/zai-org/glm-5.2"
 - "bai/minimax-m3"
 - "deepseek/deepseek-chat-v4"

# Fallback ke OpenAI jika 9Router down
fallback_providers:
 - provider: "openai"
 model: "gpt-4o-mini"
 api_key: "${OPENAI_API_KEY}"
 condition: "all"

Environment Variables

Hermes mendukung environment variable dengan sintaks ${VAR_NAME}:

# ~/.bashrc atau ~/.zshrc
export OPENAI_API_KEY="sk-..."
export ANTHROPIC_API_KEY="sk-ant-..."
export TELEGRAM_BOT_TOKEN="123456:ABC..."
export DISCORD_BOT_TOKEN="..."
export OPENROUTER_API_KEY="sk-or-v1-..."
export TOGETHER_API_KEY="..."
export 9ROUTER_API_KEY="9r-sk-..."
# config.yaml menggunakan env vars
custom_providers:
 9router:
 base_url: "http://localhost:20128/v1"
 api_key: "${9ROUTER_API_KEY}" # Akan di-resolve dari environment

Profile System

# Untuk profile baru
hermes profile create work

# List profiles
hermes profile list
# default (active)
# work
# coding

# Switch profile
hermes profile switch work

# Set config per profile
hermes config set work.model.default "nvidia/z-ai/glm-5.2"
hermes config set work.system_prompt "Anda asisten kerja..."

# Set provider per profile
hermes config set coding.model.provider "custom:9router"
hermes config set coding.model.default "Skil1Ulti"

Setiap profile memiliki direktori sendiri:

├── default/
│ ├── skills/ # Skill khusus profile ini
│ ├── plugins/
│ ├── cron/
│ └── memories/

│ ├── skills/
│ ├── plugins/
│ ├── cron/
│ └── memories/
└── coding/
 ├── skills/
 ├── plugins/
 ├── cron/
 └── memories/

Skill Management

# List skills
hermes skills list

# Create skill
hermes skill create my-skill
# Edit di ~/.hermes/profiles/default/skills/my-skill.md

# Test skill loading
hermes skill test my-skill

# Simulate skill trigger
hermes simulate "tolong deploy aplikasi" --skills deployment-runbook

# Enable/disable skill
hermes skill enable my-skill
hermes skill disable my-skill

# Delete skill
hermes skill delete my-skill
Skill file format:
---
name: My Skill
description: Deskripsi singkat
trigger: ketika user minta [tugas]
priority: normal # high, normal, low
---
