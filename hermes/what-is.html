Apa itu HermesWhat is Hermes

BerandaHome / Apa itu HermesWhat is Hermes / Apa itu Hermes

Definisi

Hermes Agent adalah framework AI agent yang dikembangkan oleh Nous Research. Framework ini memungkinkan developer membangun, mengkonfigurasi, dan menjalankan agen AI otonom yang dapat mengamati, merencanakan, dan bertindak melalui tool calling. Hermes berbeda dari framework lain karena fokus pada isolation per profil, sistem skill sebagai procedural memory, dan integrasi gateway multi-platform.

Nous Research

Nous Research adalah organisasi AI research yang berfokus pada pengembangan model dan framework open-weight. Nous dikenal melalui:

  • Model Hermes — Serangkaian model yang di-fine-tune dari Llama untuk instruction following, function calling, dan agentic workflow yang lebih baik. Model Hermes open-weight dan dapat di-host sendiri.
  • Hermes Agent — Framework agent yang mengintegrasikan model dengan tool, skill, memory, dan gateway multi-platform.
  • Open-weight philosophy — Nous percaya pada transparansi dan kontrol. Model dan framework dapat diaudit, dimodifikasi, dan di-host sendiri.

8 Fitur Hermes

1. Multi-Profile System

Setiap agen berjalan dalam profil terpisah. Profil berisi konfigurasi, skill, plugin, cron jobs, dan memories yang independen. Ini memungkinkan satu instalasi Hermes menjalankan multiple agen tanpa konflik.

~/.hermes/
├── config.yaml
├── profiles/
│ ├── default/ # Profil personal
│ │ ├── skills/
│ │ ├── plugins/
│ │ ├── cron/
│ │ └── memories/
│ ├── work/ # Profil kerja
│ │ ├── skills/
│ │ ├── plugins/
│ │ ├── cron/
│ │ └── memories/
│ └── coding/ # Profil coding
│ ├── skills/
│ ├── plugins/
│ ├── cron/
│ └── memories/

Switch profil: hermes profile switch work. Setiap profil memiliki provider, system prompt, dan tools yang berbeda.

2. Skill System

Skill adalah knowledge module yang dimuat ke dalam konteks agen saat dibutuhkan. Berbeda dari plugin (yang executable), skill adalah teks terstruktur berisi prosedur, convention, dan referensi yang membantu agen menyelesaikan tugas.

Skill bekerja seperti procedural memory: agen mengevaluasi skill mana yang relevan dengan tugas, memuatnya ke konteks, lalu menggunakan knowledge tersebut untuk bertindak. Contoh: skill deployment-runbook berisi prosedur step-by-step untuk deploy ke production.

3. Cron Jobs

Hermes mendukung scheduled task secara native. Cron job berisi schedule (cron expression), prompt (instruksi untuk agen), dan tools yang diperlukan.

# daily-report.yaml
name: Daily Report
schedule: "0 9 * * *" # Setiap jam 9 pagi
prompt: |
 Untuk laporan harian:
 1. Query database untuk metrics kemarin
 2. Bandingkan dengan threshold
 3. Kirim summary ke Telegram
tools:
 - database
 - telegram

Cron berjalan tanpa intervensi manual. Ideal untuk monitoring, report, dan maintenance task.

4. Plugin Architecture

Plugin adalah kode yang memberikan agen kemampuan baru. Plugin dapat: memanggil API eksternal, mengakses database, menjalankan command, transformasi data. Plugin terdaftar dengan schema yang jelas dan dipanggil melalui function calling.

# plugin.yaml
name: weather
description: Cek cuaca lokasi
tools:
 - name: get_weather
 description: Dapatkan cuaca untuk kota
 parameters:
 city:
 type: string
 required: true
 description: Nama kota

Plugin dapat di-enable/disable per profil untuk keamanan.

5. Memory System

Memory menyimpan informasi yang persisten antar sesi. Tiga tipe:

  • Factual — Fakta tentang user: "User bekerja di Jakarta", "Prefer dark mode"
  • Episodic — Log interaksi: "Pada 2024-01-15, user minta deploy app X"
  • Procedural — Cara melakukan tugas: "Untuk deploy, gunakan command Y"

Agen otomatis retrieve memory relevan saat processing. User dapat: "Ingat bahwa saya prefer format JSON" atau "Apa yang saya minta bulan lalu?".

6. Tool Use

Hermes dilengkapi tools bawaan:

  • Terminal — Execute shell command
  • Filesystem — Read, write, search, patch file
  • Network — HTTP request, web search
  • Code execution — Run Python/JS
  • Vision — Analyze image
  • Database — Query SQL/NoSQL

Tools dapat di-enable/disable per profil.

7. Multi-Platform Gateway

Hermes dapat terhubung ke berbagai platform messaging:

  • Telegram — Bot Telegram sebagai interface
  • Discord — Bot Discord untuk komunitas
  • Slack — Bot Slack untuk tim
  • WhatsApp — Bot WhatsApp

Satu agen dapat melayani multiple platform sekaligus.

8. Delegation

Hermes dapat spawn subagent untuk task kompleks. Subagent adalah agen terpisah dengan konteks dan tools sendiri, dikirim untuk mengerjakan bagian tertentu dari tugas, lalu melaporkan hasil ke agen utama.

Contoh: Agen utama menerima "Untuk landing page". Agen dapat spawn subagent untuk: (1) research design trend, (2) write HTML/CSS, (3) write copy, (4) optimize images. Setiap subagent berjalan independen.
