Prasyarat

  • Android 14+ (recommended)
  • Termux dari F-Droid (BUKAN Play Store version yang outdated)
  • Storage permission: termux-setup-storage
  • Koneksi internet stabil
  • Minimal 2GB free storage

Bootstrap

# Update package list
pkg update && pkg upgrade -y

# Install dependencies
pkg install -y python git nodejs curl jq nano

# Verify versions
node --version # v18+
npm --version # v9+
python --version # v3.10+
git --version

# Setup storage access
termux-setup-storage

# Set working directory
mkdir -p ~/hermes-work
cd ~/hermes-work

Install Hermes

# Install via npm
npm install -g hermes-agent

# Inisialisasi Hermes
hermes setup

# Setup akan:
# 1. Membuat ~/.hermes/ directory structure
# 2. Generate config.yaml
# 3. Membuat profile default
# 4. Prompt untuk API key / provider

# Verifikasi
hermes --version
hermes config show

Install 9Router

9Router adalah gateway yang menyediakan akses ke multiple LLM provider dengan combo, fallback, dan token saver.

# Install 9Router
npm install -g 9router

# Start 9Router (default port: 20128)
9r

# 9Router akan:
# 1. Membuat ~/.9router/ directory
# 2. Init SQLite database
# 3. Start server di http://localhost:20128
# 4. Buka dashboard di browser

Konfigurasi 9Router di Hermes config:

# Edit config.yaml
nano ~/.hermes/config.yaml
model:
 default: "bai/minimax-m3"
 provider: "custom:9router"

custom_providers:
 9router:
 base_url: "http://localhost:20128/v1"
 api_key: "your-9router-key"
 models:
 - "nvidia/z-ai/glm-5.2"
 - "aiand/zai-org/glm-5.2"
 - "bai/minimax-m3"
 - "deepseek/deepseek-chat-v4"
# Test koneksi
hermes test

Boot Sequence

Urutan startup yang benar di Termux:

1. Termux boot
 |
2. 9Router start (localhost:20128)
 |
3. Hermes Agent start
 |
4. Gateway connect (Telegram/Discord)
 |
5. Agent siap menerima perintah

Manual Boot

# Terminal 1: Start 9Router
9r
# Tunggu hingga: "9Router running on port 20128"

# Terminal 2: Start Hermes
hermes gateway start
# Tunggu hingga: "Gateway connected to Telegram"

Automated Boot (Boot Script)

# Untuk boot script
cat > ~/start-hermes.sh << 'SCRIPT'
#!/bin/bash
echo "Starting 9Router..."
nohup 9r > ~/.9router/9router.log 2>&1 &
9R_PID=$!
sleep 3

echo "Starting Hermes Agent..."
nohup hermes gateway start > ~/.hermes/logs/gateway.log 2>&1 &
HR_PID=$!
sleep 2

echo "9Router PID: $9R_PID"
echo "Hermes PID: $HR_PID"
echo "Logs: ~/.9router/9router.log and ~/.hermes/logs/gateway.log"
SCRIPT

chmod +x ~/start-hermes.sh

systemd Alternative (nohup)

Termux tidak mendukung systemd. Gunakan nohup atau termux-services:

nohup Method

# Start 9Router di background
nohup 9r > ~/.9router/9router.log 2>&1 &
echo $! # Save PID

# Start Hermes di background
nohup hermes gateway start > ~/.hermes/logs/gateway.log 2>&1 &
echo $! # Save PID

# Cek status
ps aux | grep -E "9r|hermes"

# Stop
kill -9 <PID>

Termux:Boot (Auto-start saat device boot)

# Install Termux:Boot dari F-Droid
# Buka Termux:Boot sekali untuk initialize

# Untuk boot script
mkdir -p ~/.termux/boot
cat > ~/.termux/boot/start-services << 'EOF'
#!/bin/bash
termux-wake-lock
sleep 5
nohup 9r > ~/.9router/9router.log 2>&1 &
sleep 3
nohup hermes gateway start > ~/.hermes/logs/gateway.log 2>&1 &
EOF

chmod +x ~/.termux/boot/start-services

Pitfall Section

Pitfall 1: Gateway Restart Kena SIGTERM

Masalah: hermes gateway restart atau hermes gateway stop terkadang tidak berfungsi dengan baik di Termux. Proses mendapat SIGTERM tetapi tidak mati, meninggalkan zombie process yang mengikat port.

Solusi:

# JANGAN pakai: hermes gateway restart

# GUNAKAN: kill manual + restart
# 1. Cari PID
ps aux | grep hermes

# 2. Kill dengan SIGKILL (force)
kill -9 <PID>

# 3. Pastikan port bebas
# 4. Start ulang
nohup hermes gateway start > ~/.hermes/logs/gateway.log 2>&1 &

Pitfall 2: config.yaml Patch Blocked

Masalah: Hermes patch tool tidak dapat mengedit config.yaml saat agen sedang berjalan. File dikunci oleh proses aktif.

Solusi:

# 1. Stop Hermes dulu
kill -9 $(ps aux | grep hermes | grep -v grep | awk '{print $2}')

# 2. Edit config.yaml
nano ~/.hermes/config.yaml

# 3. Start ulang
nohup hermes gateway start > ~/.hermes/logs/gateway.log 2>&1 &

Pitfall 3: Port Conflict

Masalah: Port 20128 (9Router) atau port gateway sudah digunakan oleh proses lain.

Solusi:

# Cek apa yang menggunakan port
ss -tlnp | grep 20128
# atau
netstat -tlnp | grep 20128

# Kill proses yang konflik
kill -9 <PID>

# Atau ganti port 9Router
9r --port 20129

Pitfall 4: Node.js Out of Memory

Masalah: Termux memiliki memory terbatas. Hermes + 9Router dapat OOM (Out of Memory) pada device dengan RAM < 4GB.

Solusi:

# Increase Node.js memory limit
export NODE_OPTIONS="--max-old-space-size=512"

# Atau di boot script
nohup env NODE_OPTIONS="--max-old-space-size=512" hermes gateway start ...
