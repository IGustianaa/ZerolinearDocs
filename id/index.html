APA ITU HERMES AGENT?

Lebih dari chatbot.
Agent yang benar-benar bekerja.

Hermes Agent adalah framework AI agent open-source dari Nous Research. Hermes berjalan melalui terminal, aplikasi desktop, IDE, dan platform pesan—dengan tools untuk memeriksa file, menjalankan perintah, melakukan riset web, mengotomatisasi workflow, dan menghasilkan pekerjaan nyata.

Dokumentasi resmi ↗GitHub ↗

Terus berkembang

Mengubah workflow yang berhasil menjadi skill reusable dan mempelajari cara kerja pilihan Anda.

Akses tools nyata

Bekerja dengan terminal, file, browser, API, gambar, kode, dan ekosistem Python.

Multi-platform

Gunakan agent yang sama melalui Telegram, Discord, Slack, WhatsApp, Signal, email, dan lainnya.

Bebas provider

Ganti OpenRouter, Anthropic, OpenAI, Gemini, model lokal, dan lebih dari 20 provider.

Memory & otomatisasi

Mengingat konteks penting serta menjalankan pekerjaan rutin, monitoring, dan pengiriman terjadwal.

Mudah diperluas

Tambahkan MCP server, plugin, custom tools, webhook, profile, dan skill khusus.

01 · MULAI DI SINI

Sebelum memulai

Hermes berjalan di Linux, macOS, Windows/WSL2, dan Android melalui Termux. Installer resmi menyiapkan Python, uv, environment terisolasi, dan launcher secara otomatis.

03 · ANDROID

Setup Termux

Termux adalah jalur Android praktis untuk instalasi Hermes portable. Instal dari F-Droid atau GitHub—bukan versi Play Store lama—lalu jaga perangkat tetap aktif saat gateway berjalan.

01

Siapkan Termux

Perbarui package dan instal Git. Installer Hermes menangani dependency runtime lainnya.

02

Instal Hermes

Jalankan installer resmi, selesaikan setup, lalu verifikasi chat lokal pertama.

03

Jaga gateway tetap aktif

Gunakan termux-wake-lock. Optimasi baterai Android masih dapat menghentikan proses panjang.

SHELL
pkg update -y
pkg install git python -y
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
hermes setup
termux-wake-lock
Panduan resmiPeriksa catatan Android terbaru di dokumentasi Hermes Termux ↗.

Yang berfungsi dan yang tidak

DidukungSesi CLI dan TUI, cron job, gateway Telegram, tool file dan kode, MCP, skill, memory.
TerbatasTranskripsi suara dan pemrosesan media berat bergantung pada paket Termux yang tersedia.
Tidak didukungDocker, dan apa pun yang memerlukan runtime browser desktop penuh.

Masalah Termux yang sering muncul

Gateway mati di backgroundJalankan termux-wake-lock dan matikan optimasi baterai untuk Termux.
Build paket gagalJalankan pkg update -y && pkg upgrade -y lebih dulu, lalu pasang ulang.
Command not found setelah instalBuka sesi Termux baru agar launcher masuk ke PATH.
Versi Play Store bermasalahPasang Termux dari F-Droid atau GitHub — build Play Store sudah usang.

07A · KREDIT GRATIS

Router dengan kredit awal gratis

Layanan berikut adalah pihak ketiga, bukan integrasi resmi Hermes. Semuanya menyediakan endpoint yang kompatibel dengan OpenAI atau Anthropic sehingga dapat dipakai Hermes sebagai custom provider. Besaran kredit dan katalog model sering berubah — anggap setiap angka di bawah sebagai titik awal yang wajib diverifikasi di dashboard penyedia.

LayananKredit gratis yang diiklankanJenis APICatatan

Arahkan Hermes ke router kompatibel OpenAI

BASH
# 1. Daftar, buat key, dan salin base URL persis dari dashboard
# 2. Simpan kredensial, lalu pilih model secara interaktif
hermes config set OPENAI_BASE_URL https://api.example-router.ai/v1
hermes config set OPENAI_API_KEY sk-key-anda
hermes model
hermes chat -q "Balas OK jika router ini berfungsi."

Router kompatibel Anthropic

BASH
export ANTHROPIC_BASE_URL="https://agentrouter.org/"
export ANTHROPIC_AUTH_TOKEN="sk-key-anda"
export ANTHROPIC_API_KEY="sk-key-anda"
Peringatan keamanan: Router mana pun dapat membaca seluruh prompt yang Anda kirim. Jangan pernah melewatkan source code rahasia, data pelanggan, atau kredensial melalui endpoint gratis pihak ketiga, dan tetap siapkan provider utama sebagai cadangan.

Opsi deployment

Install globalJalur tercepat untuk satu mesin. Memasang router sebagai paket npm global.

BASH
# Jalankan router, pastikan merespons sebelum menyentuh Hermes
curl -s http://127.0.0.1:20128/v1/models | head

Hanya lokal: Bind router ke 127.0.0.1 kecuali Anda sudah mengamankannya secara sengaja. Router terbuka yang menyimpan key provider sama dengan kebocoran kredensial yang menunggu terjadi.

Tier 1 — Basic

MARKDOWN
# SOUL.md

## Identity
I am a careful, helpful assistant.

## Communication
- Answer the question directly, then add context if useful.
- Match the language the user writes in.
- When a request is ambiguous, ask one clear question.

## Boundaries
- Confirm before deleting, overwriting, or sending anything externally.
- Never print secrets, tokens, or private paths.

Tier 2 — Pro

MARKDOWN
# SOUL.md

## Identity
I am an execution-focused engineering assistant.

## Traits
Direct. Concrete. Verifiable.

## Communication
- Lead with the answer or the command; keep explanation short.
- Reference exact file paths and commands.
- No filler, no motivational language, no unnecessary disclaimers.

## Working style
- Verify results with a real check instead of assuming success.
- Ask only when a decision has a real trade-off.

## Boundaries
- Confirm before destructive or irreversible operations.
- Keep credentials out of output and out of version control.

Tier 3 — Expert

MARKDOWN
# SOUL.md

## Identity
I am a senior autonomous operator for engineering and product work.

## Traits
Decisive. Rigorous. Self-correcting.

## Communication
- Deliver the outcome first, then the minimum supporting detail.
- Surface risks explicitly instead of hedging.

## Working style
- Plan multi-step work, execute without asking for each step.
- Prove every external side effect with a verifiable handle.
- Turn a repeated successful workflow into a skill.

## Boundaries
- Still confirm destructive, irreversible, or publishing actions.
- Never bypass authentication, quotas, or platform rules.
- Never store or echo secrets.

FAQ

Pertanyaan yang Sering Diajukan

Jawaban ringkas dan jelas untuk pertanyaan yang paling sering muncul sebelum dan setelah instalasi pertama.

01Platform mana yang sebaiknya dipilih?

Pilih Termux untuk eksperimen portable, macOS atau Windows untuk pekerjaan lokal harian, dan Linux/VPS untuk gateway yang harus selalu online. Hermes menggunakan alur inti yang sama pada semua environment tersebut.

02Apakah Hermes wajib menggunakan VPS?

Tidak. VPS bersifat opsional. Jalankan Hermes secara lokal di komputer atau Android terlebih dahulu. Gunakan VPS hanya ketika Anda membutuhkan ketersediaan 24/7 yang independen.

03Apakah Hermes dapat berjalan di Android?

Ya. Termux merupakan jalur praktis yang didukung untuk Android. Instal prerequisite, jalankan installer resmi, dan gunakan termux-wake-lock selama gateway aktif.

04Apakah setup Termux dapat dipindahkan ke VPS?

Ya. Instal ulang Hermes di VPS, pindahkan hanya konfigurasi dan skill yang diperlukan, pulihkan credential secara aman, lalu verifikasi provider dan gateway sebelum mengalihkan traffic.

05Di mana konfigurasi dan credential disimpan?

Hermes menyimpan konfigurasi di ~/.hermes/config.yaml dan credential di ~/.hermes/.env. Jaga file .env tetap privat dan jangan pernah mempublikasikan token asli.

06Mengapa perubahan konfigurasi belum terlihat?

Restart gateway setelah mengubah konfigurasi gateway atau provider. Mulai session baru setelah mengaktifkan tools atau skills karena kemampuan tersebut dimuat saat session dimulai.

07Mengapa bot Telegram tidak merespons?

Jalankan hermes gateway status, verifikasi token BotFather dan authorized users, lalu periksa ~/.hermes/logs/gateway.log. Pastikan juga provider model yang dipilih dalam kondisi sehat.

08Apakah model atau provider dapat diganti nanti?

Ya. Jalankan hermes model untuk membuka interactive picker. Credential pool juga dapat dikelola melalui hermes auth tanpa membangun ulang skills atau workflow gateway.
